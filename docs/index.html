This is the web site for the Fischl Family Tree starting with Leb (Lobl) 1730. The probability is that Lobl was the patrynomic. His son adopted/was given the surname of Fischl as a result of the 1787 Hapsburg edict for surnames to be used.

This Tree is work in progress and is regularly updated.

Whilst it is not intended thast the tree follows non-Fischl branches, these have been populated when the records have been available.

Any additions, corrections, suggestion for improvements, should be sent by email to fischltreeimages@gmail.com, or to Gordon at ming98.solutions@gmail.com.

The starting point for populating this site was the following two documents provided by Peter Summer.

Tree 1730-1865
Tree 1820-1982

Note that there are variations in the spelling of names across the available records. In some instances it may be that a name is commonly used within the family but never referred to in official documents. There are also variations due to the difference between the Czech and German forms and then there are instances where the official records themselves vary in the spelling as a result or errors by the recorders.

The simplest way to start using these pages is to use the Family Tree link. This options helps you to avoid getting lost.

Alternatively you may start at the oldest part of the tree to which the link is below (for Leb). From there you will be able to navigate down and up through descendants and ancestors.

Finally you may start from any individual using the alphabetic People index.

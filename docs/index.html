Family History

This is the web site for the Fischl Family Tree starting with Leb (Lobl) 1730. The probability is that Lobl was the patrynomic. His son adopted/was given the surname of Fischl as a result of the 1787 Hapsburg edict for surnames to be used.

Whilst it is not intended thast the tree follows non-Fischl branches, these have been populated when the records have been available.

Any additions, corrections, suggestion for improvements, should be sent by email to fischltreeimages@gmail.com, or to ming98.solutions@gmail.com.

I hope that you find this site useful.

Thank you.

To begin using these pages you may either start at the oldest part of the tree to which the link is below (for Leb). Alternatively you may click on the People Index below from which you may select any name as you start point.

Once within the tree you will be able to navigate down an up through descendants and ancesters.
